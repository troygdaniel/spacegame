Abyssal Garden: what Long Haul can take from it

Review for card review-abyssal-garden, 16 Nov 2026. Read from the source at github.com/Noniv/abyssal-garden (MIT); nothing from it was built or run. Compared with Long Haul at bf96fca.

Build these first

1. A critic that sees only the picturesA fresh agent gets fixed screenshots and no code, and lists what looks wrong. Small.
2. A one-minute flight benchmarkOne key flies a fixed route and reports average, 99th percentile and worst frame. Medium.
3. Cards that say when they are donePriorities in order, a number to hit, and the checks that close the card. Small.

What it does well

  • The prompt is a contract. In 2 KB it gives three priorities in the order they win when they conflict, hard limits, one named machine with a frame budget (11 ms average, no frame over 16.7 ms), the scene, and two checks that define done.
  • It checks the look blind. A separate agent sees six fixed camera shots and a recording, never the code or the reasoning, and returns ranked defects. Work continues until nothing is above "minor".
  • It measures speed the same way every time. A scripted 60-second flight logs every frame and reports average, 99th percentile and worst. The flight and benchmark keys exist only in a separate dev.html.
  • It degrades by itself. Each second it compares frame time with a 60 fps target and lowers resolution first, then draw distance, in small steps, and goes back up the same way. The result is remembered for the next visit.
  • It survives a crash. A marker is set while the world loads; if it is still set on the next visit, that load crashed, and the page starts one detail level lower.
  • The menu is useful time. The scene runs blurred behind the start menu, so the speed tuning is mostly finished before play starts.
  • The README invites changes. A table says which file holds what, and five "easy first tweaks" name the exact constant to change.

What to steal, ranked for Long Haul

1
Blind visual critic on fixed shots
A fresh agent is handed only the PNGs from a fixed list of views (title, station, space in a fight, surface, map, HUD) and returns ranked defects. A visual card closes when nothing is above minor.
Long Haul has: screenshots from hudshots, stationshots and the playtests, read by the agent that wrote the code. Software drawing here is enough for pictures.
S
2
Scripted flight benchmark
A dev-only key flies the autopilot along a fixed route for 60 seconds with the resolution held, then shows frames, average, 99th percentile and worst. Troy presses it on his own machine and pastes three numbers.
Long Haul has: docs/PERF.md, which says drawing "cannot be judged without a real GPU" because headless Chrome here draws in software. This closes that gap. The same route can also drive a smoke test.
M
3
Card shape: priorities, target, done whenagentboard
Three optional lines on a build card: what wins when goals conflict, the number to hit, and the checks that close it. The agent reports those numbers in the review.
agentboard has: a free-text card body and a review body with "Checked". A template line in the dev-crew configuration is enough to start.
S
4
"Easy first tweaks" table
A short README table: what to change, the file, the constant. Flight speed, boost, hit flash, star density.
Long Haul has: 96 named constant tables and content in markdown, but no list of where to start.
S
5
Sound polish: reverb send and voice pools
One shared reverb made from five seconds of fading noise, and a small pool of reused voices for repeated effects, so a busy fight makes no new audio nodes. Sound runs from a 10 Hz timer, not the frame loop.
Long Haul has: all sound made in code already, with a limiter and an engine hum that follows thrust. It makes new nodes for each effect and has no reverb.
S
6
Live scene behind the title
Run a real Space scene with the autopilot flying, blurred and dimmed by CSS, behind the title menu; it sharpens when play starts.
Long Haul has: a title with drifting stars and passing ships, and a load of about half a second, so no loading bar is needed.
M
7
No new objects each frame
Abyssal keeps all per-frame numbers in one preallocated array. For Long Haul this means caching the HUD's fixed rings and arcs.
Long Haul has: 1.25 MB allocated a frame, left alone in PERF.md. Do it only if the benchmark in row 2 shows a bad worst frame.
M
8
Detail levels and automatic resolution
Low, Medium and High, remembered between visits, with resolution stepping down to hold 60 fps.
Long Haul has: its own code at 0.6 ms a frame and no sign of a slow machine. Build only if row 2 shows a need.
M
9
Glide along walls
On contact, push out along the surface normal and remove only the speed going into the wall.
Long Haul has: Phaser's box colliders on the surface and in the station, which already slide along straight walls. Worth it only if round rocks feel sticky.
S

Effort: S is under half a day for one agent, M is one card of about a day, L is several cards. Rows 1 to 3 are the recommended first builds.

Could our agents verify Long Haul this way?

The look: yes, now. The screenshot tools exist and software drawing gives correct pictures. The new part is who reads them: an agent with no code and no card history, so it cannot explain a defect away.

The speed: only on a real graphics card. Headless Chrome on this Mac draws in software (38 ms a frame in Space), so an agent's timing says nothing. The benchmark key puts the measurement on Troy's screen in one minute.

What not to copy

  • WebGPU with no engine. It is a rewrite. Long Haul's size is Phaser (1.2 MB), and its scenes, physics and input depend on it.
  • One minified file and a build step. Long Haul runs from plain files with no build, and mods and markdown content rely on that.
  • One big prompt for the whole game. Abyssal is a scene to fly through with no rules, saves or economy. Take the prompt's shape for each card, not its size.
  • The crash marker and phone support. Long Haul loads in half a second with no heavy GPU work, and is desktop only.
  • Its target machine. A frame budget is only useful for the machine Troy plays on; name that one.
