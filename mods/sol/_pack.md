The Sol pack. Switch it on in the Mods screen (O on the title) and Sol is a system you can jump to; switched off, the game is as it shipped.
What is real and what is invented, and the scale the distances are squeezed by, is in docs/SOL.md. The system and dock files are made by
mods/sol/_make.mjs from one table of bodies: change that file and run it, do not edit them by hand.
