The words of the Campaign's Fast rule (card space-game-campaign-fast-board): a burn needs the wing aboard. A first press with a ship out is refused, a second recalls the wing and burns when the last ship is aboard; the map's Fast button says which. They are strings of the game like those of ui.md and are kept in a file of their own because ui.md is at its row limit.

## Strings
| key | text |
|---|---|
| camp.nav.no.wingout | Wing is out: recall it first. Order again to recall and burn. |
| camp.nav.no.wingout2 | Recalling the wing, then the burn. |
| camp.nav.recalling | Recalling... {n} out. |
| camp.nav.recalltimeout | Recall timed out. Still out: {names}. |
| camp.nav.burnoff | Wing launched: burn off. |
| camp.nav.burnfoe | Hostiles near: burn off. |
| camp.map.fastout | FAST   Shift+Enter    wing is out |
| camp.map.fastask | FAST   press again: recall, then burn |
| camp.map.on | ON |
