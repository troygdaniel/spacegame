The words of the W list's rows that act on the selection (card space-game-w-uses-selection; Troy, 23 Nov 2026: "in W (All squads), Guard the target should use the target I already selected"). Attack and Guard the target name the hostile or the friend that is selected ("Attack Raider 3"), give the order at once, and are grey, with a hint of the keys that pick one, while none is. Who takes the order (a selected pilot alone, else all squads) and the two refusals the row answers Enter with. The rows' own words in the table are in the key table (src/data_controls.js).

## Strings
| key | text |
|---|---|
| camp.w.attack | Attack {name} |
| camp.w.guard | Guard {name} |
| camp.w.all | all squads |
| camp.w.nohostile.state | pick one with {keylast} {keynext} or {keynear} |
| camp.w.nofriend.state | pick a ship with {keyflast} or {keyfnext} |
| camp.no.nohostile | No hostile selected. Pick one first. |
| camp.no.nofriend | No ship selected to guard. Pick one first. |
