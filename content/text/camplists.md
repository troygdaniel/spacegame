The words of the two order lists (card one-list-keys): Q opens the fleet orders, P the ship orders; the foot of an open list names its keys, and a pilot's call says when it waits for a list to close. The rows' own words are in the key table (src/data_controls.js). A key may be in any file of this folder.

## Strings
| key | text |
|---|---|
| camp.call.hud.wait | Close the list or the map to answer |
| camp.ui.listkeys | {keyup} {keydown} move   {keypick} order   {key} or {keypause} close |
| camp.ui.listmore | {n} more below |
| camp.ui.blink | BLINK |
